# apps/web

Frontend Next.js (App Router) + TypeScript + TailwindCSS.

## Comandos

- **Arrancar en desarrollo:** `npm run dev` → http://localhost:3000
- **Build:** `npm run build`
- **Producción:** `npm run start`
- **Lint:** `npm run lint`
- **Tests:** `npm run test`
- **E2E:** `npm run test:e2e`

## Instalación

Desde la raíz del monorepo o desde esta carpeta:

```bash
cd apps/web
npm install
npm run dev
```
